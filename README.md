\# E-Commerce Sales Analytics



Project Overview

This project analyses e-commerce sales data using Python, data visualization, and Power BI to identify trends and generate business insights.



Objectives

\- Inspect and clean the dataset.

\- Perform exploratory data analysis (EDA).

\- Create meaningful visualizations.

\- Build an interactive Power BI dashboard.

\- Provide data-driven business recommendations.



Tools Used

\- Python

\- Pandas and NumPy

\- Matplotlib and Seaborn

\- Jupyter Notebook

\- Power BI

\- Git and GitHub



Dataset

The project uses an e-commerce sales dataset. Details of the columns, data quality, and cleaning procedures will be documented after analysis.



Project Status

In progress.
